# 타바타 타이머 기획서

> 버전 1.0 · 2026-10-25 · 플랫폼 Android / iOS (Flutter)

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 앱 이름(가칭) | 타바타 타이머 (Tabata Timer) |
| 한 줄 소개 | 타바타부터 HIIT·EMOM·AMRAP·휴식 타이머까지, **탭 한 번으로 시작**하는 다크 테마 운동 타이머 |
| 플랫폼 | Android, iOS — Flutter 단일 코드베이스 |
| 패키지 ID | `com.tabatatimer.tabata_timer` (iOS: `com.tabatatimer.tabataTimer`) — 출시 전 변경 가능 |

### 1.1 배경 — 타바타란?
1996년 다바타 이즈미(田畑泉) 교수 연구에서 유래한 고강도 인터벌 프로토콜.
**20초 최대 강도 운동 + 10초 휴식 × 8라운드 = 약 4분.** 짧지만 운동 중에는
화면을 볼 여유가 없을 만큼 힘들기 때문에, 타이머는 **보지 않아도(소리·음성) 알 수 있고,
봐야 할 때는 멀리서도 한눈에 보여야** 한다.

## 2. 제품 원칙

1. **원탭 시작** — 앱 실행 → `시작` 버튼까지 탭 1회. 마지막 설정을 항상 기억한다.
2. **멀리서도 보인다** — 운동 중에는 화면 전체 색으로 단계(운동/휴식)를 표시하고 숫자는 초대형으로.
3. **보지 않아도 안다** — 모든 전환을 효과음·음성·진동으로 알린다. 음악은 끊지 않는다.
4. **실수 방지** — 종료는 확인 다이얼로그, 버튼은 크게, 땀 묻은 손으로도 누를 수 있게.
5. **어두운 화면** — OLED 친화 다크 UI. 레퍼런스의 카드·레이아웃 구조는 계승하되, 색은 앱 고유의 **블루 팔레트**(인디고 → 애저 → 아쿠아)로 차별화.
6. **강도가 한눈에** — 시작 전 예상 강도, 운동 중 마스코트, 끝난 뒤 체감 강도를 같은 5단계 이모지·색으로 표현.

## 4. 기능 리서치 — 운동 타이머에 필요한 기능

운동 타이머 앱들에서 보편적으로 제공되거나, 위 시나리오에서 필요하다고 판단한 기능을 분류했다.

### 4.1 타이머 모드
| 모드 | 설명 | 주 사용처 |
|---|---|---|
| **타바타** | 운동/휴식/라운드/세트. 기본 20/10×8 | 타바타, 홈트 |
| **인터벌(HIIT)** | 타바타 + 웜업·쿨다운·세트 간 휴식·운동 이름 | HIIT, 서킷, 러닝 인터벌 |
| **EMOM** | Every Minute On the Minute — 매 간격마다 새 라운드 시작 | 크로스핏, 근지구력 |
| **AMRAP** | As Many Rounds As Possible — 제한 시간 내 최대 라운드, 탭으로 라운드 카운트 | 크로스핏, 맨몸운동 |
| **For Time** | 최대한 빨리 완료 — 스톱워치 + 랩 + 타임캡 | 크로스핏, 기록 측정 |
| **휴식 타이머** | 세트 간 휴식 카운트다운, 준비 시간 없이 즉시 시작, +15초 연장 | 웨이트 트레이닝 |

### 4.2 운동 중 경험
- 단계별 **풀스크린 컬러**(준비=앰버, 운동=레드, 휴식=그린, 세트 휴식=블루, 쿨다운=퍼플)
- 초대형 숫자 + 원형 진행 링, 고정폭 숫자(숫자가 바뀌어도 흔들리지 않음)
- 현재 라운드/세트, **다음 단계 미리보기**, 전체 경과/남은 시간, 전체 타임라인 바
- 일시정지/재개, 이전·다음 단계 건너뛰기, 휴식 +15초 연장
- 종료 시 확인 다이얼로그(실수 방지)
- **화면 켜짐 유지**(운동 중에만)

### 4.3 알림 · 피드백
- 단계 종료 **3-2-1 카운트다운 비프**(0/3/5초 선택)
- 단계 시작음: 운동 시작(높은 톤) / 휴식 시작(하강 톤) / 완료 팡파르 — 소리만으로 구분 가능
- **음성 안내(TTS)**: "운동", "휴식, 다음은 버피", "마지막 라운드", "절반 지났어요", "1분 남았어요", "운동 완료"
- 진동(햅틱) — 단계 전환 시
- 음악 앱과 **동시 재생**(음악을 끊지 않음)

### 4.4 루틴(프리셋)
- 자주 쓰는 설정을 루틴으로 저장/편집/복제/삭제
- 기본 제공 루틴: 클래식 타바타, 초보자 타바타, 더블 타바타, HIIT 30/30, 전신 서킷, EMOM 10, AMRAP 12, For Time 20
- 라운드별 **운동 이름**(서킷) — 운동 화면에 표시, 음성으로 안내
- 최근 사용 루틴 빠른 시작 배너

### 4.5 기록 · 동기부여
- 운동 완료 시 자동 기록(이름, 모드, 시간, 라운드, 완료 여부)
- 완료 화면: 축하 연출, 총 시간·라운드·**칼로리 추정(MET 기반)**
- **운동 강도(RPE) 기록** — 5단계 이모지 선택

### 4.6 강도 시각화
- **예상 강도** — 설정값(운동:휴식 비율 + 총 운동 시간)으로 5단계 추정. 타이머 탭 요약 카드와 루틴 카드에 이모지 + 신호 막대(▁▃▅▇█)로 표시
- **운동 중 마스코트** — 링 안의 이모지가 순간 강도에 반응 (운동 💪 → 😤 → 🥵, 마지막 라운드 🔥, 휴식 😅 → 😌, 세트 휴식 💧, 일시정지 ☕)
- **체감 강도** — 완료 후 RPE와 기록 목록이 같은 이모지·색 램프 사용

| 단계 | 이모지 | 예상 강도 | 체감(RPE) | 색 |
|---|---|---|---|---|
| 1 | 😌 | 가볍게 | 가벼워요 | 민트 `#2DD4BF` |
| 2 | 🙂 | 적당히 | 적당해요 | 스카이 `#38BDF8` |
| 3 | 😤 | 힘차게 | 힘들어요 | 애저 `#3D7BFF` |
| 4 | 🥵 | 고강도 | 버거워요 | 인디고 `#6366F1` |
| 5 | 🔥 | 한계 도전 | 한계예요 | 바이올렛 `#8B5CF6` |

예상 강도 = 1 + 밀도 점수(운동/휴식 ≥2 → 3, ≥4/3 → 2, ≥1 → 1, 그 외 0. EMOM·AMRAP·For Time은 1) + 시간 점수(총 운동 ≥12분 → 2, ≥5분 → 1), 최대 5.
- 주간 운동 시간 차트, 운동 횟수, **연속 운동일(스트릭)**
- 날짜별 기록 목록, 삭제

### 4.7 설정
- 효과음 / 음성 안내 / 진동 on/off
- 카운트다운 비프 길이, 절반 알림, 준비 시간(0/5/10/15초)
- 화면 켜짐 유지, 체중(칼로리 계산용)
- 기록 초기화

### 4.8 확장 아이디어(백로그)
- 잠금화면/백그라운드 진행 알림, iOS Live Activity·Dynamic Island, Android 포그라운드 서비스
- Apple Watch / Wear OS 연동, 심박수, Apple 건강·Health Connect 기록
- 홈 화면 위젯(원탭 시작), 루틴 공유(링크/QR), 가로 모드·태블릿 레이아웃
- 음성 언어/목소리 선택, 사용자 효과음, 다국어
- 운동 동작 라이브러리(GIF), 운동 프로그램(4주 챌린지), 리마인더 알림

## 6. 화면 설계

### 6.1 정보 구조
```
앱
├─ 하단 탭
│  ├─ 타이머  : 모드 선택 → 값 조절 → 시작        (홈)
│  ├─ 루틴    : 루틴 카드 목록 → ▶ 시작 / ⋮ 편집·복제·삭제 / ＋ 새 루틴
│  ├─ 기록    : 주간 요약·차트 → 날짜별 기록
│  └─ 설정    : 사운드·타이머·화면·데이터
├─ 운동 진행 (풀스크린)  → 완료 화면 (요약 · 강도 기록)
└─ 루틴 편집 (풀스크린)
```

### 6.5 루틴 / 기록 / 설정 탭
- **루틴**: 알람 카드 스타일 — 소제목(모드), 큰 숫자(총 시간), 요약(20초·10초·8라운드), 우측 ▶ 버튼과 ⋮ 메뉴, 우하단 레드 FAB(＋).

### 7.4 배경 · 알림
- **오로라 배경**: 남색 다크 위에 큰 빛 두 덩이가 인디고 → 바이올렛 → 애저로 24초에 걸쳐 천천히 색과 위치를 바꿈(불투명도 0.3 / 0.13). 초당 12프레임만 갱신, 앱이 백그라운드거나 ‘동작 줄이기’ 설정이면 멈춤. 메인 탭과 완료 화면에 적용
- **운동·휴식 카드**: 인디고 → 틸 그라데이션 테두리 + 아주 옅은 애저 톤으로 아래 카드와 구분. 비율 막대(26dp) 안에 각 비율을 넣고, 구간이 좁아지면 숫자만, 더 좁으면 숨김
- **알림(Android)**: 시스템 진행 템플릿은 접힌 상태에서 막대를 그리지 않아 직접 만든 레이아웃 사용. 막대는 앱과 같은 그라데이션·라운드 마디·현재 위치 표시를 이미지로 그림. Android가 구간을 최대 10개까지만 그려서 단계 → 라운드 → 세트 → 균등 분할 순으로 묶음(`notificationSegments`). 매초 갱신

### 7.5 앱 아이콘
- 인디고 `#5457FF` → 애저 `#3D7BFF` → 아쿠아 `#1FC7E9` 대각선 그라데이션 + 좌상단 하이라이트 (블루 시안 4종 비교 후 선택)
- 흰색 **8칸 말굽형 링**(타바타 8라운드, 6칸 진행 · 2칸 남음), 위쪽 열린 자리를 **TIMER** 워드마크가 닫고, 가운데 **7-세그먼트 "0:20"**(타바타 20초). 글자·숫자는 모두 직접 그린 둥근 선이라 폰트 라이선스가 필요 없음. 배치 4종 비교 후 선택
- 정렬: 렌더링한 심볼의 실제 무게중심을 측정해 맞춤. 링 중심을 캔버스 중심보다 30px 위(482/1024)에 두어 무게중심이 정중앙 바로 아래(≈516)에 오도록 하고, 숫자를 키우고 워드마크를 가볍게 해 위쪽 쏠림을 줄임
- 생성: `python3 tool/gen_icon.py`(SVG + PNG) → `dart run flutter_launcher_icons`
  - Android: 일반 + 적응형(배경/전경 분리, 안전 영역 맞춤) + 13+ 테마(단색) 아이콘
  - iOS: 기본 + 18+ 다크(그라데이션 심볼) · 틴트(단색) 아이콘

## 8. 사운드 · 음성 · 진동 설계

| 이벤트 | 효과음 | 음성(TTS, 한국어) | 진동 |
|---|---|---|---|
| 준비 시작 | — | "준비하세요" | — |
| 타이머가 도는 매초 | 부드러운 짧은 "삐-"(1kHz, 설정에서 끄기 가능) | — | — |
| 단계 종료 3초 전부터 | 또렷한 짧은 "삐-"(1.3kHz) ×3 | — | 약 |
| 구간 종료 → 운동 시작 | 긴 "삐---"(높은 음) | "운동 시작" / "스쿼트 시작" / 마지막이면 "마지막 라운드! 운동 시작" | 강 |
| 구간 종료 → 휴식 시작 | 긴 "삐---"(낮은 음) | "휴식" / "휴식. 다음은 버피" | 강 |
| 세트 휴식 | 긴 "삐---"(낮은 음) | "세트 휴식. 다음은 2세트" | 강 |
| EMOM 라운드 시작 | 긴 "삐---"(높은 음) | "3라운드 시작" | 강 |
| 절반 경과(30초 이상 운동) | — | "절반 지났어요" | — |
| 1분 남음(2분 이상 단계) | — | "1분 남았어요" | — |
| 운동 완료 | 상승 팡파르 | "운동 완료! 수고하셨어요" | 강 |

- 음성은 긴 비프가 잦아들 때(0.5초 뒤) 시작해 겹치지 않게 한다.
- **목소리**: 기기의 한국어 음성 중 가장 자연스러운 것을 자동 선택(iOS 프리미엄 > 향상됨 > 기본, Android 최고 음질 > 고음질, 기기 내장 우선). 설정 › 목소리에서 미리 듣고 바꿀 수 있다. 삼성 TTS는 다른 앱에 열려 있지 않아 Galaxy에서는 Google 음성 엔진을 쓴다.
- **오디오 세션**: iOS `playback + mixWithOthers`(무음 스위치 무시, 음악 유지, 덕킹 없음), Android 오디오 포커스 미점유 → 음악 위에 안내음이 겹친다.
- **백그라운드**: Android는 운동 중 포그라운드 서비스(mediaPlayback, 웨이크락)와 진행 알림("휴식 · 라운드 1/8"), iOS는 `UIBackgroundModes: audio` + 운동 중 무음 루프로 오디오 세션을 유지해 화면이 꺼져도 타이머·소리가 계속된다.
- 효과음은 `tool/gen_sounds.py`로 직접 합성(저작권 이슈 없음).

---|---|---|---|
| 준비 시작 | — | "준비하세요" | — |
| 단계 종료 N초 전 | 짧은 비프(1kHz) ×N | — | 약 |
| 운동 시작 | 긴 고음 비프 | 운동 이름 또는 "운동" / 마지막이면 "마지막 라운드" | 강 |

| 웜업 / 쿨다운 | 하강 2음 | "웜업" / "쿨다운" | 강 |
| EMOM 라운드 시작 | 긴 고음 비프 | "N라운드" | 강 |
| 절반 경과(30초 이상 단계) | — | "절반 지났어요" | — |

- 효과음은 앱에서 직접 합성한 WAV(저작권 이슈 없음).

## 10. 기술 설계

| 항목 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Flutter 3.47 / Dart 3.13 | Android·iOS 단일 코드 |
| 상태 관리 | `ChangeNotifier` + `InheritedWidget`(AppScope) | 외부 의존 최소, 코드 단순 |
| 저장 | `shared_preferences` | 소량 JSON |
| 효과음 | `audioplayers` (lowLatency) | 짧은 비프 저지연 재생, 믹싱 설정 |
| 음성 | `flutter_tts` (ko-KR) | OS 내장 TTS |
| 화면 유지 | `wakelock_plus` | 운동 중에만 활성 |
| 진동 | Flutter `HapticFeedback` | 추가 의존 없음 |

### 10.1 타이머 엔진 원칙
- 운동 전체를 **단계 목록(IntervalStep[])으로 미리 계산** → 화면·소리·기록 모두 같은 데이터 사용
- 경과 시간은 `Timer` 누적이 아닌 **시계 차이로 계산**(드리프트 없음, 백그라운드 복귀 시 자동 보정)
- 위치(position) 하나로 현재 단계·남은 시간을 도출 → 건너뛰기는 위치 오프셋 조정만으로 처리
- 큐(비프·음성·진동)는 엔진이 이벤트로 발행, 재생은 CuePlayer가 설정에 따라 처리 → 엔진 단위 테스트 가능

### 10.2 폴더 구조
```
lib/
├─ main.dart, app.dart          앱 시작, 테마, 하단 탭 셸
├─ theme/                       컬러 토큰, ThemeData
├─ models/                      WorkoutConfig, IntervalStep, WorkoutRecord, AppSettings
├─ engine/                      단계 계산(workout_plan), 실행기(workout_runner), 큐
├─ data/                        저장소(설정·루틴·기록·타이머 설정), AppScope, 기본 루틴
├─ services/                    CuePlayer(효과음·음성·진동), 칼로리 계산
├─ utils/                       시간·날짜 포맷
└─ ui/                          timer / routines / history / settings / workout / widgets
assets/sounds/                  합성 효과음(WAV)
tool/gen_sounds.py              효과음 생성 스크립트
```
